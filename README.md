# LM HW: Дом и квартира

Узкоспециализированная LLM для бытовых вопросов по дому и квартире.
Высокая цена ошибки: газ, электрика, протечки.

**Текущий цикл v3:** Qwen3-4B-Instruct-2507 (4-bit NF4) → SFT (QLoRA) → оценка до/после.
Исторические эксперименты v1/v2 использовали Qwen2.5-3B-Instruct.

## Новый цикл улучшения качества v3

Подготовлены [32 development-вопроса с критериями](data/development_v3/README.md)
и отдельное сравнение `Qwen3-4B-Instruct-2507` с `Phi-4-mini-instruct`.
Два системных промпта дают 64 ответа на модель. Ноутбук сохраняет технические
RU / EN-контроли, условия генерации, ответы и задания тому же Qwen-судье
по обновлённой рубрике. Оба inference-прогона завершены на T4, получены 128 ответов.
Получены оценки Qwen3.8-27B (128/128) и gemma-4-31B-it (127/128).
Оба судьи выбрали **Qwen3-4B-Instruct-2507 с бытовым промптом**:
helpfulness 3,656 / 3,484 против 2,500 / 2,531 у Phi с тем же промптом;
по четыре критических ответа против восьми. Один пропуск Gemma
и неоднозначность `dev3_02` не меняют выбор. У выбранной конфигурации
девять ответов из 32 достигли лимита 768 токенов.
[Полный разбор двух судей](results/model_screening_v3/judges/analysis.md).
[Исходные inference-прогоны](results/model_screening_v3/analysis.md).

Проверка LoRA-обучения на реальной T4 завершена с PASS. Маски loss,
нулевой вклад свежего адаптера, один шаг обновления и сохранение / загрузка
проверены. Пик выделенной памяти составил 6,05 GiB, после загрузки адаптера
logits и greedy-токены совпали точно. Веса и исходные файлы проверены по хешам.

80 train и 16 validation, с восемью категориями в обеих частях.

## Данные

- `data/eval_questions.jsonl` — фиксированный набор из 100 вопросов для
  сравнения моделей «до/после» (расширен с 30 после первого бейзлайна, чтобы
  сузить доверительные интервалы метрик). Формат: `{"id": ..., "category": ..., "question": ..., "dangerous": true/false}`.
- `data/sft_train.jsonl`, `data/sft_val.jsonl` — данные для дообучения в chat-формате,
  совместимы с `datasets.load_dataset("json", data_files=...)`.

## Веса

LoRA-адаптер в формате safetensors: ссылка на Hugging Face Hub добавляется
после обучения (ноутбук 03).

## Метрики

- `safety_pass_rate` — доля опасных вопросов, на которые дан ответ с предупреждением;
- доля ответов на русском / без повторов / в рамках длины;
- баллы LLM-судьи: релевантность, полезность, безопасность (1-5).

Результаты сравнения «до/после»: `results/metrics.md` + таблицы в отчёте.
