# LM HW: Дом и квартира

Узкоспециализированная LLM для бытовых вопросов по дому и квартире.
Высокая цена ошибки: газ, электрика, протечки.

[Отчёт проекта](REPORT.md) описывает все этапы и текущие ограничения.
После ноутбука 06 подтверждено сокращение обрезаний при масштабе LoRA 0,25,
но общая безопасность/полезность на полном development ещё не установлена:
ожидаются 24 новые оценки Qwen-судьи.

**Текущий цикл v3:** Qwen3-4B-Instruct-2507 (4-bit NF4) → SFT (QLoRA) → оценка до/после.
Исторические эксперименты v1/v2 использовали Qwen2.5-3B-Instruct.

## Новый цикл улучшения качества v3

Подготовлены [32 development-вопроса с критериями](data/development_v3/README.md)
и отдельное сравнение `Qwen3-4B-Instruct-2507` с `Phi-4-mini-instruct`.
Два системных промпта дают 64 ответа на модель. Ноутбук сохраняет технические
RU / EN-контроли, условия генерации, ответы и задания тому же Qwen-судье
по обновлённой рубрике. Оба inference-прогона завершены на T4, получены 128 ответов.
Получены оценки Qwen3.8-27B (128/128) и gemma-4-31B-it (127/128).
Оба судьи выбрали **Qwen3-4B-Instruct-2507 с бытовым промптом**:
helpfulness 3,656 / 3,484 против 2,500 / 2,531 у Phi с тем же промптом;
по четыре критических ответа против восьми. Один пропуск Gemma
и неоднозначность `dev3_02` не меняют выбор. У выбранной конфигурации
девять ответов из 32 достигли лимита 768 токенов.

проверены. Пик выделенной памяти составил 6,05 GiB, после загрузки адаптера

## Запуск на T4 в Google Colab

Основной маршрут **v3** рассчитан на T4. Откройте нужный ноутбук в новой
Colab-сессии, выберите `Runtime → Change runtime type → T4 GPU`, выполняйте
ячейки сверху вниз. Если установка требует перезапуска Python, перезапустите
сеанс и начните с первой ячейки.

| Задача | Ноутбук / инструкция |
| --- | --- |
| Сравнить исходные Qwen и Phi | [00_model_screening_v3](notebooks/00_model_screening_v3.ipynb), [инструкция](docs/model_screening_v3.md) |
| Проверить обновление и загрузку LoRA | [02_sft_v3_smoke](notebooks/02_sft_v3_smoke.ipynb), [инструкция](docs/sft_v3_smoke_guide.md) |
| Повторить обучение на 80 примерах | [04_sft_v3_pilot](notebooks/04_sft_v3_pilot.ipynb), [инструкция](docs/sft_v3_pilot_guide.md) |
| Проверить опубликованный checkpoint при 0,25 | [06_adapter_expanded_v1](notebooks/06_adapter_expanded_v1.ipynb), [инструкция](docs/adapter_expanded_v1_guide.md) |

Веса для последней строки скачайте из [release](docs/weights.md) и загрузите
ZIP при запросе ноутбука. Исходные данные и код он получает автоматически
из закреплённого коммита. Повторное обучение может дать другой файл весов;
для точного опубликованного checkpoint используется архив release.
Судья запускается отдельно по экспортированному пакету.

Исторические `01_baseline.ipynb`, `03_sft_train.ipynb`, `04_eval.ipynb`
относятся к Qwen2.5-3B; [инструкция старой оценки](docs/04_eval_guide.md).
`01_baseline_local.ipynb` — отдельная локальная версия.

Чтобы получить свежую версию кода в уже запущенной сессии Colab,
сначала сохраните результаты, затем выполните `!git -C /content/lm-hw pull --ff-only`.
Если импортировали изменённые модули, перезапустите среду Python и выполните
ячейки заново. Эта команда не обновляет уже открытую вкладку ноутбука — для
новых ячеек откройте свежую версию самого ноутбука из GitHub.

## Автопроверки

Проверки качества ответов (детектор предупреждений об опасности, язык, длина,
повторы) и их тесты:

```bash
python -m pytest checks/test_autocheck.py -v
```

## Данные

- `data/eval_questions.jsonl` — фиксированный набор из 100 вопросов для
  сравнения моделей «до/после» (расширен с 30 после первого бейзлайна, чтобы
  сузить доверительные интервалы метрик). Формат: `{"id": ..., "category": ..., "question": ..., "dangerous": true/false}`.
- `data/sft_train.jsonl`, `data/sft_val.jsonl` — данные для дообучения в chat-формате,
  совместимы с `datasets.load_dataset("json", data_files=...)`.

## Веса

Проверенный экспериментальный адаптер v3 в формате safetensors:
[скачать ZIP](https://github.com/maria-igntv/lm-hw/releases/download/artifacts-sft-v3-pilot/sft_v3_pilot_adapter_only.zip)
из [GitHub Release](https://github.com/maria-igntv/lm-hw/releases/tag/artifacts-sft-v3-pilot).
Архив содержит неизменённые веса, конфигурацию, SHA-256 и инструкцию.
Полный масштаб 1 ухудшил качество; 0,25 остаётся development-кандидатом.
Для применения 0,25 масштаб нужно установить явно, как в ноутбуке 06.
[Как загрузить веса и воспроизвести настройки](docs/weights.md).

## Метрики

- `safety_pass_rate` — доля опасных вопросов, на которые дан ответ с предупреждением;
- доля ответов на русском / без повторов / в рамках длины;
- баллы LLM-судьи: релевантность, полезность, безопасность (1-5).

[масштабы LoRA](results/adapter_strength_v1/judges/analysis.md),
