# LM HW: Дом и квартира

Узкоспециализированная LLM для бытовых вопросов по дому и квартире.
Высокая цена ошибки: газ, электрика, протечки.

**Базовая модель:** Qwen2.5-3B-Instruct (4-bit NF4) → SFT (QLoRA) → оценка до/после.

## Выбор следующей базы

Для предварительного сравнения Qwen3-4B-Instruct-2507 и Qwen2.5-7B-Instruct
подготовлены 16 новых русских вопросов и
[ноутбук 00_model_screening](notebooks/00_model_screening.ipynb).
Первый прогон Qwen3-4B завершён, 9 из 16 ответов достигли лимита 384 токена.
[Разбор первого прогона](results/model_screening/qwen3_4b_t384/analysis.md).
Для общего сравнения двух моделей лимит увеличен до 768, результаты и оценки
нового протокола ещё предстоит получить.
[Пошаговый план](docs/model_screening.md).
[Открыть скрининг в Colab](https://colab.research.google.com/github/maria-igntv/lm-hw/blob/main/notebooks/00_model_screening.ipynb).

## Диагностика исходной модели

Выполнено сравнение русских/английских запросов в Transformers 4.57.3 и 5.22.1
на одном закреплённом чекпоинте без адаптера и квантизации. На 12 запросах
входные и выходные токены совпали между версиями, проблемы русского текста
воспроизвелись. [Полный разбор и воспроизведение](results/diagnostics/README.md).

## Данные

- `data/eval_questions.jsonl` — фиксированный набор из 100 вопросов для
  сравнения моделей «до/после» (расширен с 30 после первого бейзлайна, чтобы
  сузить доверительные интервалы метрик). Формат: `{"id": ..., "category": ..., "question": ..., "dangerous": true/false}`.
- `data/sft_train.jsonl`, `data/sft_val.jsonl` — данные для дообучения в chat-формате,
  совместимы с `datasets.load_dataset("json", data_files=...)`.

## Веса

LoRA-адаптер в формате safetensors: ссылка на Hugging Face Hub добавляется
после обучения (ноутбук 03).

## Метрики

- `safety_pass_rate` — доля опасных вопросов, на которые дан ответ с предупреждением;
- доля ответов на русском / без повторов / в рамках длины;
- баллы LLM-судьи: релевантность, полезность, безопасность (1-5).

Результаты сравнения «до/после»: `results/metrics.md` + таблицы в отчёте.
