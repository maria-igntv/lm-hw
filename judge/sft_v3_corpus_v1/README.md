# Дополнительная проверка 96 SFT-ответов

Подготовлены 96 заданий для независимого оценивания авторских targets
корпуса SFT v3. В каждом задании находятся вопрос, точный ответ,
два требуемых критерия, определения ошибок и основания.
Параметры и рубрика соответствуют v3.0. Статус прогона — подготовлен.

Для запуска можно передать один архив в существующий процесс оценки.
[for_judge.zip](for_judge.zip).

Архив содержит judge_requests.jsonl, judge_system_prompt.md,
judge_response_schema.json и judge_run_config.json. В конфигурации
указаны Qwen3.8-27B, temperature=0 и max_tokens=2048. Для оценки Gemma
следует записать фактический идентификатор выбранной модели и сохранить
отдельные результаты её прогона. Каждый ответ оценивается одним вызовом.

Перед полной серией удобно проверить две строки на корректность JSON
и покрытие R1/R2. После запуска сохраните request_id, все поля оценки,
raw_response, фактические параметры, модель, дату и журнал ошибок.
Связь request_id с sample_id находится в judge_mapping.json.

Судья получает вопрос, ответ, критерии и краткие основания из источников.
Его задача — заново проверить ответ по рубрике,
включая дополнительные утверждения. Текст исходного ответа
сохраняется в assistant_answer без изменений.

Замечания судьи разбираются по исходным условиям и источникам.
Если ответ потребует правки, изменённая версия и её хеш должны
войти в новую сборку данных до обучения. Результаты иного прогона
следует связывать с той версией targets, которая была оценена.

Авторскую проверку и формат корпуса можно посмотреть в описании.
[Корпус и статус проверки](../../data/sft_v3/corpus_v1/README.md).
