# Оценка SFT-пилота v3: 64 ответа

Пакет [for_judge.zip](for_judge.zip) извлечён из завершённого прогона
`qwen3_4b_20261118T113449101907`. Точное соответствие всех 64 текстов
исходным ответам и содержимое ZIP проверены анализатором.
Получены и проверены 64/64 оценки от каждого из двух судей — Qwen и Gemma.
[Разбор и артефакты](../../results/sft_v3_pilot/judges/analysis.md).
Статус package_manifest.json фиксирует момент подготовки исходного пакета.

Внутри четыре файла:

- judge_requests.jsonl — 64 строки, 32 baseline и 32 SFT в перемешанном порядке;
- judge_system_prompt.md — зафиксированная рубрика v3.0;
- judge_response_schema.json — схема полного ответа;
- judge_run_config.json — temperature=0, max_tokens=2048, JSON Schema.

Для каждого запроса передайте `system_prompt` как system-сообщение,
`user_prompt` как user-сообщение. Сохраняйте исходный request_id,
полный разобранный JSON, сырой ответ, ошибки и метаданные запуска.
Ожидаются 64 валидные оценки от Qwen3.8-27B; при возможности
тот же ZIP можно независимо передать gemma-4-31B-it.

Название модели и фаза скрыты от судьи. Таблица соответствия
judge_mapping.json находится отдельно и в ZIP не включена.
В текст ответа не добавляется фраза «Оцени ответ ассистента».
Дополнительные короткие greedy-контроли загрузки в пакет не входят.

Нужно вернуть метаданные фактически использованной модели, время,
параметры, 64 результата по request_id и журнал ошибок.
Пропуски и некорректный JSON следует повторить с теми же параметрами;
полученные содержательные оценки не заменяются вручную.

В dev3_02 есть ранее зафиксированная неоднозначность: в самом вопросе
не указано слово «газовая». Примечание сохранено в review_notes.json,
итоговое парное сравнение также покажет результат без этого вопроса.
Исходная рубрика сохранена, чтобы оценки были сопоставимы с прошлым этапом.
